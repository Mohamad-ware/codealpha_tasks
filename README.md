# CodeAlpha Machine Learning Tasks

Machine-learning projects completed for the CodeAlpha internship. Each task is self-contained in
its own folder, with its own README and `requirements.txt`.

| Task | Project | Techniques |
|------|---------|------------|
| 1 | [Credit Scoring](Task1_CreditScoring/) | Predicts serious loan delinquency from financial history (Kaggle *Give Me Some Credit*). EDA, feature engineering, Logistic Regression, Decision Tree, Random Forest |
| 3 | [Handwritten Character Recognition](Task3_HandwrittenCharacterRecognition/) | Recognises handwritten digits and letters (MNIST / EMNIST) with a CNN, and whole words with a CRNN + CTC sequence model (PyTorch) |
| 4 | [Disease Prediction from Medical Data](Task4_DiseasePrediction/) | Predicts heart disease, diabetes and breast cancer (UCI datasets) with SVM, Logistic Regression, Random Forest and XGBoost (scikit-learn) |

## Getting started

```bash
git clone https://github.com/Mohamad-ware/codealpha_tasks.git
cd codealpha_tasks/<task-folder>
pip install -r requirements.txt
```

Then follow that task's README.
